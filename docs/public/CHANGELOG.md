# 변경 기록

## 0.7.1

- 펜 색 버튼에 현재 색상 견본 표시.
- 옆에 스포이드 추가: 메모 안에서 보이는 색을 집어 펜 색으로 사용, Esc/우클릭 취소.
- 선택 손잡이 제외, 이미지 불투명도와 겹침을 반영한 색 채취.
- 자동 검사 40개 통과. 대용량 이미지·장기 사용 검증은 수행하지 않음.

## 0.7.0

- 불투명도와 자르기를 분리하고 기존 통합 팝업 제거.
- 배치된 이미지에 실시간 반영하는 인라인 불투명도 슬라이더.
- 3분할 격자·8개 손잡이·제외 영역 음영으로 직접 자르기. 이미지 밖 더블클릭/Enter 확정, Esc 취소.
- 반복 자르기에서 원본 범위 복원 가능. 원본 파일은 보존.
- 편집 중 자동 저장 보류, 명시적 저장·종료 시 확정, 실행 취소와 잠금 준수.
- 불투명도 미리보기에서 이미지 재디코딩 없음. 38개 검사와 짧은 유휴 자원 측정.
- 읽기 전용 제목에 포커스가 있을 때 캔버스 단축키를 막지 않으며, 슬라이더 방향키는 요소 이동과 분리.

## 0.6.0

- 가로/세로 동일 간격 배치와 요소 잠금/해제.
- 다중 선택 전체 테두리와 비율 유지 크기 조절, 글자·여백 함께 조절.
- 새 필기를 투명 PNG로 저장하고 픽셀 부분 지우개 지원. 기존 벡터 필기와 호환.
- 펜/지우개 크기 슬라이더, 원형 미리보기·수치, 도구별 아이콘.
- 문서 스키마 4, 잠금·부분 지우기·묶음 변형·간격·복구 포함 35개 검사 통과.

## 0.5.0

- 메모별 Flow 토글, 마우스 기준 확대, 휠 버튼/Space 드래그로 화면 이동.
- 영역 확장 메뉴와 Flow 오른쪽·아래 자동 확장, 가려진 선택 항목으로 이동.
- Shift/범위 다중 선택, 그룹/해제, 묶음 드래그·방향키 이동·삭제와 실행 취소.
- 이미지 불투명도·백분율 자르기·미리보기·원상복구. 원본은 보존.
- 문서 스키마 3, 구문서 읽기와 새 기능 백업 복원 검사 포함 33개 검사 통과.
- 실제 IME·복수 DPI·장기 상주는 추가 검증 필요. 직접 끌어서 이미지 자르기와 그룹 전체 크기 조절은 미포함.

## 0.4.0

- 마우스 오버 표시를 제거하고 좌상단 버튼만으로 도구를 토글합니다.
- 도구를 종이 위에 겹쳐 표시해 화면상 내용 위치와 전체 맞춤 배율을 유지합니다.
- 메모 배경색을 도구에도 적용하고 UI 글자를 대비가 높은 검정/흰색으로 자동 선택합니다. 본문 서식은 유지합니다.
- 별도 이동 손잡이를 없애고 상단 제목 표시줄로 창을 이동합니다. 제목은 더블클릭 편집, Enter/Esc/포커스 이동으로 편집을 마칩니다.
- 숨김 상태의 저장 실패는 독립적인 재시도 알림으로 표시합니다.

- 공개 문서/게시 대상 분리와 로컬 데이터 추적 방지.
