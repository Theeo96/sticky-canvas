# 로컬 데이터 형식

기본 위치: `%LOCALAPPDATA%\StickyCanvas`. 트레이의 ‘데이터 폴더 열기’로 확인할 수 있습니다.

SQLite의 `notes`는 문서 ID와 JSON, `views`는 창 위치·크기·보기 설정, `assets`는 이미지 파일 정보·체크섬을 저장합니다. 문서는 글상자·도형·이미지·필기의 배열이며 각 ID·위치·크기·순서를 유지합니다.

글씨는 문단/글자별 서식 데이터, 필기는 경계 상자 안에 정규화된 점 목록·색·굵기입니다. 실행 가능한 XAML/HTML을 저장하지 않습니다.

- 스키마 1: 기본 글상자·도형·이미지.
- 스키마 2: 필기를 추가한 문서. 기존 문서는 필기를 넣기 전까지 스키마 1 유지.

DB 쓰기는 트랜잭션과 WAL을 사용하며 실행 중 `-wal`, `-shm` 보조 파일이 생길 수 있습니다. 저장 완료 응답 전에 완료로 표시하지 않으며 실패하면 재시도 UI를 드러냅니다.

이미지는 `assets`에 복사하므로 원본을 옮겨도 앱 사본이 남습니다. 자동 DB 복구본은 SQLite backup API로 만들고 최근 7개를 보관합니다. 복구본 DB가 이미지 원본을 대체하지는 않습니다.

ZIP은 문서와 이미지를 함께 담습니다. 가져오기는 경로·크기·버전·체크섬을 검사한 뒤 새 ID의 사본을 추가합니다. 현재 한도는 명세 16 MiB, 이미지 20 MiB/25MP, 전체 가져오기 512 MiB입니다.

업데이트 전 저장 확인 후 트레이에서 종료하세요. 실행 중 DB를 외부 도구로 덮어쓰지 마세요. 앱 자체 암호화는 현재 없습니다.


v0.5: 그룹 ID와 이미지 불투명도·원본 기준 정규화 자르기 범위는 스키마 3 문서에 저장합니다. 원본 첨부 해시는 유지합니다. Flow 모드·배율·화면 이동 위치는 기기별 보기 설정이며 본문 좌표와 분리합니다. 구버전 앱은 스키마 3 문서를 지원하지 않습니다.


v0.6 문서 스키마 4는 Locked와 IsDrawing을 추가합니다. 픽셀 필기는 image 요소와 PNG AssetId로 저장하며 벡터 좌표는 남기지 않습니다. 지우개는 변경한 PNG를 새 첨부로 저장하고 실행 취소에서는 이전 해시를 복구합니다. 기존 stroke 요소는 읽기를 유지합니다. 펜/지우개 크기는 기기 보기 설정에 저장합니다.


v0.7.2의 WindowOpacity는 NoteView에 저장하는 nullable 배율(0.2~1)입니다. 필드가 없으면 1(불투명)이며 문서 스키마 변경은 없습니다. 요소 찾기 필터는 stroke/IsDrawing을 제외할 뿐 문서에서 삭제하지 않습니다.
