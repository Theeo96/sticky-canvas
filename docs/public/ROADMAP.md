# 개발 계획

각 묶음은 구현 → 격리 검증 → 실사용 → 피드백 순서로 진행합니다. 저장/입력 오류는 새 기능보다 먼저 수정합니다.

| 단계 | 범위 | 상태 |
|---|---|---|
| 1 | Windows 포스트잇·글상자·도형·이미지·로컬 저장·백업 | 제공 |
| 1 개선 | 내용만 보기·상단 도구 토글·겹쳐 표시·자동 대비·제목 표시줄 이동·로그인 자동 실행 | v0.4에서 보완 |
| 2-A | 펜·색·굵기·선 지우개·필기 저장 | 제공 |
| 2-B 일부 | 종이 기준 정렬·이동 격자 맞춤 | v0.3 제공 |
| 2-B | 다중 선택·그룹 이동·Flow·영역 확장·이미지 편집 | v0.5 제공 |
| 2-B | 간격 맞춤·잠금·전체 크기 조절·픽셀 필기·부분 지우개 | v0.6 제공 |
| 2-C | 인라인 이미지 편집·안정성 회귀 검사·짧은 자원 측정 | v0.7 제공 |
| 2-C 검증 | 대용량 이미지 단기 부하·저장/복구 검증 | v0.7.1에서 약 7분·75회 확인, 메모리 개선 후보 발견 |
| 2-C 다음 | 반복 이미지 편집 메모리 최적화·이후 장시간 검증 | 예정 |

| 4 | 모바일 편집·오프라인·홈 화면 위젯 | 예정 |
| 5 | 선택한 글상자 텍스트에 한정한 AI 연동 | 예정 |

웹/모바일은 플랫폼별 화면과 공통 문서 계약·API를 사용할 계획입니다. 위젯은 미리보기와 앱 진입부터 시작합니다. AI는 텍스트 수정 계약만 제공하고 배치·사진·도형의 임의 변경을 제한할 계획입니다.

구현 완료와 실제 장치·IME·배율·장기 사용 검증을 구분합니다. 다음 작업 주제는 **대용량 이미지 반복 편집 메모리 최적화**입니다.
