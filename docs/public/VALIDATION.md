# v0.9 검증 기록 · 2026-11-17

## 15분 예비 상주

사용자 선택에 따라 실제 수시간 대신15분 예비 검증과 장기 도구 제공 범위로 수행했습니다. 테스트 시작 시점의 v0.8.0 실행 파일을 별도 프로필에 복사해 사용했으며, 이번 v0.9 웹 기능을 포함한 실행 파일의 수시간 검증을 의미하지 않습니다.

인공 JPEG 3장(4096×3072 두 장, 5000×5000 한 장)을 메모3개에 참조9개로 배치했습니다. 실제 경과901.63초, 반복 편집75회, 창 닫기·재열기·트레이 상주·정상 종료 후 별도 프로세스 재실행과 ZIP 복원 검사를 수행했습니다.

| 항목 | 결과 |
|---|---|
| 저장 데이터 재열기 | 일치 |
| 원본 이미지3개 해시 | 일치 |
| 복원 | 메모3개·이미지참조9개 |
| 피크 작업 집합 |242.37MiB|
| 마지막 작업 집합/전용 할당 |205.40/211.99MiB|
| 강제 GC/메모리 비우기 |사용하지 않음|

이 결과로 수시간/수일 안정성이나 누수 부재를 확정하지 않습니다. `scripts/test-long-session.ps1`의 기본값은 실제7200초이며, `-DurationSeconds 900`으로 예비 검증을 재현할 수 있습니다. 실제 실행 시간은 지정시간에 편집 처리 시간이 더해질 수 있습니다. 시험 도구의 타이머는 일반 앱 동작에 추가하지 않았습니다.

## DPI

연결 모니터3개의 배율 목록은150%,100%,125%였습니다. 별도 DPI 도구를 앱과 같은 DPI manifest로 컴파일해 확인했습니다. 100/125/150/175/200%에서 WPF 오프스크린 렌더링과 문서↔화면 좌표 왕복을10~800% 메모 배율에서 확인했습니다. 앱에는 DPI 변경 후 보기 배율·펜 포인터 갱신을 추가했습니다.

실제 서로 다른 DPI 모니터 사이로 창을 이동하는 입력 시험, 물리 펜의 위치·복수 DPI에서의 선택 손잡이 실기 검증은 수행하지 않았습니다. `scripts/test-dpi.ps1`의 결과도 해당 한계를 명시합니다.

## 웹 기반

자동 검사47개와 Node의 텍스트 서식 보존/변경 포맷 검사를 통과했습니다. 브라우저에서 인공 작업 파일 열기→갤러리→상세→텍스트 편집→변경 파일 다운로드→실제 다운로드 파일을 데스크톱 저장소에 반영하는 왕복을 확인했습니다. 이미지 ID와 배치를 보존했습니다.

데스크톱에서 바뀐 메모의 버전/해시 충돌은 전체 트랜잭션을 중단하고 일부 메모만 반영하지 않습니다. 잠긴 글상자·텍스트가 아닌 요소에 대한 변경은 거절합니다. 브라우저는 외부 통신을 하지 않으며 실제 인증·클라우드 자동 동기화는 아직 구현하지 않았습니다. 작업 파일은 암호화되지 않은 개인 데이터이므로 사용자 소유 파일로 취급합니다.
