# 공개 범위

소스 코드, 앱 아이콘, 빌드/검증 도구와 이 공개 문서만 저장소에 포함합니다. Releases 패키지는 EXE·런타임 설정·일반 사용 안내만 담습니다.

다음 항목은 Git에서 제외합니다.

- 실제 사용자 메모·사진·DB·WAL/SHM·백업
- `.local/`, `evidence/`, `bin/`, `release/` 산출물
- 로컬 운영 문서·작업 기록·개인 경로·다른 프로젝트 연결 정보
- 환경 변수 파일·키·실행 로그

실행 파일에 메모 내용은 포함하지 않습니다. 데이터는 실행 시 Windows 사용자 데이터 폴더에서 별도로 읽고 씁니다. 이 폴더를 Git에 복사하지 마세요. 테스트 소스의 예문·이미지는 인공 데이터입니다.

`scripts/check-public-files.ps1`는 추적 대상 경로와 텍스트를 검사합니다. 모든 개인정보 탐지를 보장하지 않으므로 게시 전 diff도 검토해야 합니다.

자동 실행은 현재 사용자 Run 키의 앱 전용 항목만 사용하며 앱에서 해제할 수 있습니다. 실행할 때마다 강제로 켜지 않습니다. 기본 실행은 외부 메모 서비스에 데이터를 전송하지 않습니다.
