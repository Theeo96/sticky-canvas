# 앱 아이콘

노란 포스트잇 한 장, 접힌 오른쪽 아래 모서리, 짧은 갈색 두 줄을 사용한다. 문자·그림자·배경 장식 없이 작은 트레이에서도 식별되도록 만든 벡터 원본이다. 이미지 생성 모델 없이 SVG로 직접 제작했다.

- 원본: `app-icon.svg` (256×256, 투명 배경)
- Windows 아이콘: `app-icon.ico` (16/20/24/32/40/48/64/128/256px)
- 미리보기·후속 플랫폼용: `app-icon-{크기}.png`
- 색상: 종이 `#F6D56F`, 접힘 `#DCA947`, 줄 `#70582E`

`scripts/build-icon.ps1`가 SVG를 읽어 PNG와 ICO를 재생성한다. 앱 빌드 때 실행 파일의 네이티브 아이콘과 내장 리소스로 함께 넣는다. 트레이와 WPF 창은 같은 내장 리소스를 읽으며 외부 이미지 파일 설치가 필요하지 않다.
