# Sticky Canvas · 캔버스 메모

<img src="assets/app-icon-128.png" alt="캔버스 메모 아이콘" width="80" />

바탕화면의 포스트잇처럼 쓰는 **Windows 네이티브 캔버스 메모 앱**입니다. 글상자·도형·이미지·손그림을 한 메모 안에서 자유롭게 배치합니다.

현재 버전: **v0.7.3** · Windows x64 · C# / WPF / .NET Framework 4.8 · 로컬 저장

## 기능

- 메모별 독립 창, 크기 조절, 항상 위, 트레이 상주. 작업표시줄/Alt+Tab에 표시하지 않습니다.
- 평소에는 내용과 작은 좌상단 버튼만 표시합니다. 좌상단 버튼으로만 **상단 도구**를 열고 닫습니다.
- 글상자·글꼴·크기·색·굵게·기울임·밑줄·문단 정렬.
- 도형과 이미지, 이동·크기·앞뒤 순서·복제.
- 펜·색·굵기·선 지우개. 글상자·도형·이미지·서식을 선택하면 그리기 모드를 자동 해제합니다.
- 종이 기준 정렬과 이동 시 8칸 격자 맞춤.
- 자동 저장, 검색, 휴지통·복구, 실행 취소, ZIP 백업/사본 가져오기.
- Windows 로그인 시 자동 실행 옵션.

## 실행

GitHub Releases의 Windows ZIP을 압축 해제하고 `StickyCanvas.exe`를 실행합니다. `.config` 파일을 같은 폴더에 둡니다. .NET Framework 4.8이 필요합니다.

트레이 더블클릭은 목록, 우클릭은 새 메모·백업·자동 실행·완전 종료입니다. 창의 `×`는 창만 닫습니다. 완전 종료는 **트레이 → 캔버스 메모 종료**입니다.

상단 도구는 내용 위에 겹쳐 표시합니다. 열고 닫아도 내용의 화면 위치·표시 배율은 바뀌지 않습니다. 도구 배경은 메모와 같은 색이고, UI 글자는 배경 대비에 따라 검정/흰색으로 바뀝니다. 메모 본문의 지정 색상은 유지합니다. 창 이동은 상단 제목 표시줄 드래그, 제목 편집은 더블클릭입니다. 글 편집은 더블클릭/Enter, 그리기 종료는 선택/Esc입니다. `서식 ▾`는 펼치기, `서식 ▴`는 접기입니다.

## 데이터와 개인정보

기본 데이터는 `%LOCALAPPDATA%\StickyCanvas`에 저장합니다.

| 경로 | 내용 |
|---|---|
| `notes.sqlite3` | SQLite DB. 문서 본문은 구조화된 JSON, 창 설정·첨부 정보도 보관 |
| `assets/` | 이미지 원본 사본 |
| `backups/` | 일별 DB 복구본 |

**이 저장소에는 실제 메모·사진·DB·백업·실행 로그를 포함하지 않습니다.** 테스트는 인공 데이터만 사용합니다. 기본 실행은 로컬 동작이며 클라우드/AI 연결과 앱 자체 암호화는 아직 없습니다.

## 빌드

Windows PowerShell에서 실행하며 PowerShell 7을 권장합니다.

```powershell
pwsh -File scripts/build.ps1 -Test
pwsh -File scripts/package.ps1
```

외부 NuGet 패키지는 사용하지 않습니다. 설치된 Visual Studio C# 컴파일러를 우선 사용하고 없으면 Windows .NET Framework 컴파일러를 사용합니다. 결과는 `bin/`, 패키지는 `release/`에 생성합니다. 검사는 별도 인공 데이터 프로필을 사용합니다.

게시 전 점검: `pwsh -File scripts/check-public-files.ps1`.

## 범위와 제한

- Windows x64 로컬 앱입니다. 웹·모바일·동기화·AI 연동은 후속 계획입니다.
- 필기 문서는 스키마 2입니다. v0.1.0에서는 읽을 수 없습니다.
- PNG/JPEG 기본 지원. WebP는 Windows 코덱에 따라 달라집니다.
- 실제 IME 조합·복수 배율·재로그인·장기 상주는 환경별 추가 검증이 필요합니다.
- 비공식 바탕화면 부모 창 부착은 사용하지 않습니다. Win+D/가상 데스크톱 표시 동작은 미검증입니다.
- 시험판 EXE는 코드 서명되지 않았습니다.

## 넓게 편집하기 · v0.5

`고정` 왼쪽의 **Flow** 버튼으로 전환합니다. Flow는 휠, 기본 모드는 Ctrl+휠로 마우스 위치를 중심으로 확대합니다. 글 편집 중에는 Ctrl+휠을 사용합니다. 휠 버튼 드래그 또는 편집 중이 아닐 때 Space+드래그로 화면을 이동합니다. 모드 전환은 문서 요소를 변경하지 않습니다.

**영역 ▾**에서 오른쪽·아래 확장, 크기 지정, 전체/100% 보기, 선택 항목으로 이동을 제공합니다. 확장은 기존 요소의 좌표·크기를 유지합니다. Flow에서는 창을 넓히거나 요소를 오른쪽·아래로 이동하거나 펜이 경계에 접근하면 영역이 늘어납니다. 창을 줄여도 내용은 삭제하지 않습니다. 최대 8192×8192이며 왼쪽·위쪽으로 문서를 확장하지는 않습니다. 도구를 열어도 화면을 밀지 않으며, 바깥 여유 공간으로 화면을 이동해 가린 요소를 볼 수 있습니다.

Shift+클릭 또는 빈 공간 드래그로 여러 요소를 선택합니다. 손잡이 드래그와 방향키는 선택 묶음을 이동합니다. **선택 ▾**에 전체 선택·그룹·그룹 해제·선택 삭제가 있습니다. Ctrl+A, Ctrl+G, Ctrl+Shift+G도 지원합니다. 영구 그룹은 상대 배치를 유지하며 함께 선택됩니다. 선택 전체 테두리의 모서리 손잡이로 묶음의 비율과 상대 배치를 유지하며 크기를 조절합니다.

이미지 우클릭에서 **◐ 이미지 불투명도**와 **⌗ 이미지 자르기**를 별도로 실행합니다. 불투명도는 메모 아래의 슬라이더를 움직이면 놓인 이미지에 즉시 반영됩니다. 적용/Enter 또는 다른 곳 클릭으로 확정하고 취소/Esc로 되돌립니다. 자르기는 원본 위의 3분할 격자와 8개 손잡이를 직접 조절합니다. 제외되는 영역은 어둡게 표시하고, 이미지 밖 더블클릭·적용·Enter로 확정합니다. Esc는 취소입니다. 확정 후에도 자르기 모드를 다시 열어 원본 범위 안에서 경계를 늘릴 수 있습니다. **이미지 원상복구**는 자르기와 불투명도를 초기화하며, 원본 파일은 변경하지 않습니다.

그룹·이미지 편집은 **문서 스키마 3**을 사용합니다. 기존 문서는 계속 읽지만, 새 기능 사용 후에는 구버전 앱으로 돌아가지 마세요. 데이터 폴더의 원본을 보존하고 업데이트 전에 ZIP 백업을 권장합니다.

## 픽셀 필기와 배치 · v0.6

- 새 펜 그림은 투명 PNG 첨부로 저장합니다. 객체 크기를 바꾸면 선 두께도 그림과 함께 확대·축소됩니다. 기존 벡터 필기는 계속 표시하며 부분 지우개 사용 시 픽셀로 전환합니다. 픽셀 그림은 확대하면 픽셀이 보일 수 있습니다.
- 지우개는 글·일반 사진·도형을 건드리지 않고 필기의 닿는 픽셀만 투명하게 만듭니다. 드래그 한 번이 실행 취소 한 번입니다. 이미지 첨부는 변경 이력용 사본으로 저장하며 원본을 덮어쓰지 않습니다.
- 펜 크기 1~64px, 지우개 크기 1~128px 슬라이더와 원형 미리보기·현재 수치를 제공합니다. 원형 미리보기는 최대 32px로 제한하며 실제 크기는 옆 수치로 표시합니다.
- 여러 요소 선택 후 전체 테두리의 모서리를 드래그하면 전체를 비율 유지 확대·축소합니다. 글자 크기와 여백도 함께 조절합니다. 문서 경계와 지원 글꼴 크기 범위에서는 크기 변경이 제한됩니다.
- **↖ 선택 ▾**의 가로/세로 간격 맞춤은 3개 이상 선택했을 때 첫 항목과 마지막 항목을 고정하고 사이 간격을 균등하게 만듭니다. 영구 그룹은 한 항목으로 계산합니다.
- 선택 메뉴 또는 요소 우클릭의 잠금/해제로 편집을 방지합니다. 잠긴 요소는 선택해서 해제할 수 있으며, 포함된 묶음 전체의 변형·삭제는 차단됩니다. 잠금 표시 ▣를 제공합니다.
- 도구 버튼에 글상자 T, 도형 ◇, 이미지 ▧, 서식 Aa, 배치 ⊞, 영역 ▱, 선택 ↖, 목록 ☷ 아이콘을 붙였습니다.

픽셀 필기·잠금은 **문서 스키마 4**를 사용합니다. 이전 문서를 읽을 수 있으며 새 기능을 쓴 문서는 구버전 앱으로 열지 마세요. 자동 검사 35개를 통과했으며 실제 IME·복수 DPI·장기 상주는 별도 확인 사항입니다.

## 안정성과 자원 점검 · v0.7

통합 수치 입력 팝업을 제거했습니다. 이미지 편집 중에는 자동 저장이 도구를 닫지 않으며, 미리보기는 문서에 반영하지 않습니다. 명시적 저장·정상 종료는 편집을 확정해 저장합니다. 각 편집은 실행 취소 한 번으로 복원하며 잠긴 이미지는 편집할 수 없습니다.

슬라이더 미리보기는 현재 이미지의 표시 불투명도만 바꾸며 파일 읽기·이미지 디코딩·전체 메모 재생성을 반복하지 않습니다. 별도의 장기 이미지 캐시·유휴 폴링·강제 GC는 추가하지 않습니다. 200회 미리보기에서 재디코딩이 없는지 검사합니다. 자동 저장 지연·Esc 취소·반복 자르기·저장·기존 기능을 포함해 38개 격리 검사를 통과했습니다.

자원 측정 범위와 결과는 [자원 점검 기록](docs/public/PERFORMANCE.md)에 기록합니다. 짧은 인공 데이터 측정은 실제 대용량 이미지·복수 DPI·장기 사용 검증을 대신하지 않습니다.

## 펜 색상 견본·스포이드 · v0.7.1

펜 색 버튼의 작은 사각형에 현재 펜 색을 표시합니다. 버튼을 누르면 기존 색상 선택기를 사용할 수 있습니다. 옆의 **⌖ 스포이드**를 누르고 메모 안의 색을 클릭하면 그 색으로 펜 모드에 돌아갑니다. Esc·우클릭 또는 스포이드 버튼을 다시 눌러 취소할 수 있습니다.

스포이드는 메모 배경·글·도형·이미지·필기가 겹쳐 보이는 색을 채취합니다. 불투명도가 적용된 이미지도 화면에 합성된 색을 사용하며, 선택 테두리와 손잡이는 제외합니다. 도구 메뉴나 앱 밖 화면을 채취하는 기능은 포함하지 않습니다. 확대·축소 상태에서도 메모 좌표를 기준으로 채취합니다. 클릭할 때만 한 픽셀을 렌더링하며 상시 화면 캡처나 타이머를 추가하지 않습니다.

색상 견본·합성 이미지 채취·확대 시 일관성·그리기 없이 펜 모드 복귀를 포함한 자동 검사 40개를 통과했습니다. 대용량 이미지는 약 7분·편집 75회의 단기 부하와 저장·복구를 확인했습니다. 메모리 유지량 개선이 필요하며 수시간 이상의 장기 검증은 남아 있습니다. 상세 수치는 [자원 점검 기록](docs/public/PERFORMANCE.md)에 있습니다.

## 요소 찾기와 메모 전체 불투명도 · v0.7.2

`⋯ → 요소 선택 / 가려진 요소 찾기`에서는 펜으로 그린 요소를 제외합니다. 기존 벡터 stroke와 새 픽셀 필기 모두 제외하며, 실제 메모 내용·직접 클릭 선택·다중 선택은 유지합니다. 일반 이미지는 계속 목록에 표시합니다. 목록에서 요소를 고르면 도구에 가리지 않는 위치로 화면을 이동합니다.

`⋯ → ◐ 메모 전체 불투명도…`의 슬라이더로 메모 창 전체를 20~100% 범위에서 조절합니다. 낮을수록 바탕화면이 비치며, 글·그림·사진·메모 도구가 함께 투명해집니다. 100% 버튼으로 복원합니다. 값은 메모별 기기 보기 설정에 저장하고 재실행 시 복원합니다. 본문 색상·이미지 자체 불투명도·원본 파일은 바뀌지 않습니다. 완전히 보이지 않는 창을 방지하기 위해 최소 20%입니다.

자동 검사 42개를 통과했습니다. 펜촉·브러시 스타일은 이번 버전에서 추가하지 않았습니다.

## 800% 확대와 펜 포인터 · v0.7.3

최대 확대를 800%로 늘렸습니다. Flow 휠/기본 모드 Ctrl+휠 조작은 그대로이며, 모드별 배율과 재실행 저장값도 800%까지 지원합니다.

펜 모드에서는 실제 굵기의 중심 표시를 최소 20px의 빈 원이 감쌉니다. 1px 펜은 100%에서 1px, 800%에서 8px의 실제 영역을 표시합니다. 굵은 펜은 내용이 가려지지 않도록 실제 굵기 영역도 윤곽으로 표시합니다. 흰색·검은색 이중 윤곽으로 배경 대비를 유지합니다. 포인터는 메모·이미지·스포이드 채취에 포함되지 않으며, 마우스 이동 시에만 갱신하고 반복 타이머나 커서 비트맵을 생성하지 않습니다.

자동 검사 43개 통과. 대용량 이미지 반복 편집 메모리 최적화는 후속 과제입니다.
